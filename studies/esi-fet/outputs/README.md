# outputs/

Tables and figures. **Disposable by design** — everything here is regenerated by
`../analysis/00_run_all.R`.

Empty until the SAP is locked and the analysis runs.

## Why this directory is the source of truth for numbers

`CLAUDE.md` rule 2: no number appears in a draft unless it is traceable to a file
here. When a co-author or reviewer asks where a figure came from, the answer is a
filename and the script that produced it.
