# drafts/abstract/

The ASPIRE 2027 congress abstract.

## Constraints

From `../../../../venues/aspire-2027/guidelines/abstract-rules.md`
(inherited from ASPIRE 2026, **not yet confirmed for 2027**):

- Title **25 words, UPPER CASE**
- Body **300 words including acknowledgements**
- Mandatory structure: **Background and Aims · Methods · Results · Conclusions**
- One topic category from 20. Likely **"ART, Clinical"**.

## Workflow

1. `abstract-builder` skill drafts to the budget.
2. `protocol-guard` checks the science.
3. `aspire-compliance` checks the rules and counts the words.
4. Co-author review.
5. Submit. Freeze the submitted text in `venues/aspire-2027/submissions/`.
