R scripts. Nothing written yet — the SAP is not locked, and code written before
the plan is locked tends to become the plan.

## Planned structure

```
00_run_all.R        Orchestrator. One command reproduces everything in outputs/.
01_load.R           Read the de-identified extract from ../data/
02_derive.R         ΔET, ESI %, daily ESI, embryo categories, eligibility flags
03_cohort.R         Apply inclusion/exclusion; emit the flow-diagram counts
04_describe.R       Table 1, Table 2, missingness report
05_primary.R        Multivariable logistic regression, ESI continuous
06_spline.R         Restricted cubic spline; Figure 3
07_models.R         Model A/B/C/D comparison, AUC, calibration, Brier, DCA
08_subgroups.R      The four prespecified subgroups; interaction test
09_validation.R     Bootstrap; temporal validation if applicable
```

## Rules

- **ESI is derived in code, never typed by hand.** ET1 and ET2 are the raw inputs.
  See handoff §33.
- Everything in `../outputs/` is regenerated by `00_run_all.R`. No hand-edited
  tables or figures.
- Set and record a seed. Bootstrap results must be reproducible.
- Record R and package versions in the output.
- The script must never write patient-level data outside `../data/`.

`rms` splines and validation · `pROC` discrimination · `dcurves` decision curves ·
`mice` imputation · `tidyverse` · `gtsummary` tables
