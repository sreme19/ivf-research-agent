# ASPIRE 2027 — submission guidelines

## Status: NOT OBTAINED (as of 29 August 2026)

This directory is empty of official rules. That is a blocker, not a formality.

The detailed abstract guidelines are not published on either
https://aspire2027.com or https://aspire-reproduction.org. The congress site
directs enquiries to **abstract@aspire2027.com**.

## Why this blocks drafting

The difference between a 250-word structured abstract and a 400-word free-form one
is the difference between two entirely different documents. A 250-word structured
limit, for a study with a spline analysis and a model comparison, means most of the
methods detail is cut and the result has to carry the abstract alone. Drafting
before this is known means drafting twice.

Additional unknowns that change what can be submitted at all:

- **Prior-publication policy** — whether work presented or published elsewhere is
  eligible.
- **Whether results are required.** Some congresses accept "results pending"
  abstracts; most do not. If ASPIRE does not, the 6 November deadline requires
  completed analysis, which tightens the whole timeline.
- **Topic categories** — determines which track this is judged in, and against whom.
