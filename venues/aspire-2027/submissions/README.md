# Submissions to ASPIRE 2027

What was actually submitted, when, and what happened.

Nothing submitted yet.

## Record for each submission

Create `<study-id>-<date>.md` containing:

- Study and its folder in `studies/`
- Exact text submitted (the version of record, frozen — not a link to a draft
  that will keep changing)
- Topic category chosen
- Submission date and confirmation reference
- Presenting author
- Word count as submitted, against the stated limit
- Outcome: accepted / rejected, oral / poster / e-poster
- Any reviewer feedback received
- Presentation date and session, if accepted

## Why freeze the text here

`studies/*/drafts/` keeps moving as the manuscript develops. Six months later,
when a reviewer asks how the abstract differed from the paper, the submitted text
must be recoverable exactly as sent.
