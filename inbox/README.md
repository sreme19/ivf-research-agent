# inbox

Raw material, dated and unprocessed. **Nothing here is authoritative.**

Facts become authoritative only when compiled out into `venues/` or `studies/`
with their provenance recorded. This directory exists so that the original source
of any claim stays recoverable, and so that a revised handoff doesn't silently
overwrite reasoning built on the earlier version.

## Before dropping a file here

Check it for patient identifiers first. See `CLAUDE.md` rule 1. If it contains
names, MRNs, dates of birth or contact details, it does not belong in this repo
at all — not even in `inbox/`.
